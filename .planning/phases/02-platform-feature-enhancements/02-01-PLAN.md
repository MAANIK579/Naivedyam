<objective>
Enable rich food dish photo URLs across the entire Navedyam catalog, including backend seeding, admin media editing with live previews, and mobile catalog browsing with graceful emoji fallbacks.

Purpose:

Output:
- Updated seed script with authentic food photography URLs for all catalog dishes
- Enhanced Admin `MenuPage.jsx` with Image URL form input, live preview thumbnail, and table image rendering
- Enhanced Mobile screens (`HomeScreen.js`, `MenuScreen.js`, `ItemDetailModal.js`, `CartScreen.js`) rendering dish photos with emoji fallback
</objective>

<objective>
Implement customer self-cancellation for initial order states (`placed`, `confirmed`) with reason capture and real-time kitchen notification, and enhance the delivery address system with GPS coordinates, landmark guidance, and custom delivery instructions.

Purpose:
Giving customers the flexibility to self-cancel accidental orders before food preparation starts reduces friction and kitchen waste (FEAT-02). Providing precise GPS pin coordinates and delivery instructions ensures delivery riders can locate customer doorsteps accurately (FEAT-03).

Output:
- Enhanced backend `POST /api/orders/:id/cancel` with real-time socket events (`order:status_update`, `kitchen:order_cancelled`)
- Mobile `TrackScreen.js` and `OrdersScreen.js` with Cancel Order action, reason picker modal, and instant UI state updates
- Schema and route enhancements for `delivery_instructions`, `lat`, and `lng` in `User.js`, `Order.js`, and `addresses.js`
- Mobile `AddAddressScreen.js` with GPS coordinates capture, landmark field, and delivery instructions input
</objective>

<task type="auto" id="02-02-01">
<title>Harden backend order cancellation and real-time socket notification</title>
<instruction>
Update `backend/routes/orders.js` in `POST /api/orders/:id/cancel`:
1. Verify user ownership (`order.user.toString() === req.user.id`).
2. Enforce status rule: allow cancellation ONLY if `order.status === 'placed' || order.status === 'confirmed'`. If order is `preparing`, `out_for_delivery`, or already `delivered`/`cancelled`, return 400 with a descriptive error message.
3. Update `order.status = 'cancelled'`, `order.payment_status = 'cancelled'`, `order.cancelled_at = new Date()`, and store `order.cancellation_reason = req.body.reason || 'Cancelled by customer'`.
4. Push status history record `{ status: 'cancelled', timestamp: new Date(), note: order.cancellation_reason }`.
5. Emit real-time Socket.IO events via `req.app.get('io')`:
   - To room `order:${order._id}`: emit `order:status_update` with `{ orderId: order._id, status: 'cancelled', reason: order.cancellation_reason }`.
   - To room `kitchen`: emit `kitchen:order_cancelled` and `order:cancelled` with `{ orderId: order._id, display_id: order.display_id, reason: order.cancellation_reason }`.
</instruction>
